# Gelik Config Tools

Статическое веб-приложение для редактирования `config.json` модов.

Для GitHub Pages загрузите корневые файлы и папки редакторов:

- `index.html`
- `styles.css`
- `i18n.js`
- `classnames-manager.js`
- `classnames-data.js`
- `classnames.json`
- `modernstash/`
- `randomgifts/`
- `airdrop/`

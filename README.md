# Gelik Config Tools

Статическое веб-приложение для редактирования `config.json` мода Gelik ModernStash.

## Как использовать

1. Откройте `index.html` в браузере или разместите репозиторий на GitHub Pages.
2. При необходимости на главной странице нажмите `Настройка класснеймов` и загрузите общий JSON класснеймов. Он будет сохранен в браузере и доступен редакторам.
3. На главной странице выберите нужный редактор: `ModernStash Config Editor` или `RandomGifts Config Editor`.
4. Нажмите `Загрузить JSON` и выберите `config.json` нужного мода.
5. Базовый список из `classnames.json` в корне загружается автоматически при открытии сайта.
6. При необходимости в редакторе также можно нажать `Настройки класснеймов` и изменить общий список/фильтры.
7. Отредактируйте stash-группы, classnames, способы открытия и loot items.
8. Нажмите `Скачать config.json`, чтобы сохранить готовый файл на компьютер.

Все данные обрабатываются локально в браузере. Серверная часть не нужна.
Текущий config каждого редактора, выбранная группа, состояние JSON preview и общий список classnames сохраняются в браузере и восстанавливаются после переходов между страницами или обновления.

## Формат classnames JSON

По стандарту доступны ванильные classnames. Свои classnames добавляйте отдельным JSON-файлом.

```json
{
  "CfgVehicles": { "scope1": [], "scope2": [] },
  "CfgWeapons": { "scope1": [], "scope2": [] },
  "CfgMagazines": { "scope1": [], "scope2": [] },
  "CfgAmmo": { "scope1": [], "scope2": [] },
  "CfgNonAIVehicles": { "scope1": [], "scope2": [] }
}
```

В окне `Класснеймы` можно включать/выключать категории и общий фильтр `scope1` / `scope2`.
Категория `Vanilla` содержит класснеймы из стандартного `classnames.json` в корне сайта. Если отключить `Vanilla`, в списке останутся только пользовательские класснеймы из загруженного JSON. Дубликаты между Vanilla и пользовательским JSON не показываются повторно.

## Размещение на GitHub Pages

1. Загрузите `index.html`, `styles.css`, `classnames-manager.js`, `classnames.json`, `README.md`, папки `modernstash/` и `randomgifts/` в GitHub repository.
2. Откройте `Settings` -> `Pages`.
3. В `Build and deployment` выберите `Deploy from a branch`.
4. Выберите ветку `main` и папку `/root`.
5. Сохраните настройки и дождитесь публикации сайта.

## Подсказки полей

Тексты всплывающих подсказок лежат в `tooltips.js`. Можно менять только значения строк, ключи лучше не переименовывать.
